# infrastructure-rag

Infrastructure runbook retrieval service with a measurable token-overlap baseline, optional BM25, local semantic search and hybrid RRF. Responses are assembled from sources, not generated by an LLM.

## Local Web Workspace

The API also serves an offline-capable browser interface at `/`: queries with
top-K selection, ranked snippets and scores, recommended actions, evidence,
downloadable JSON, in-memory session query history, index status, and reindexing.
It uses the same service as the existing API; there is no LLM generation.
No Node.js, CDN, or additional packages are needed. Runtime provides a retriever
dropdown, BM25 k1/b, candidate multiplier and Apply settings. GET `/ui/config`
shows the active configuration; POST `/ui/config` builds a replacement service
and publishes it only after successful indexing. Existing API JSON fields are
unchanged. Queries carry an `X-RAG-Runtime` response header; the UI binds each
result, score tooltip and exported JSON to that snapshot, not the current form.
Old results remain available after applying settings; rerun the query for a new
comparison. History labels identify the original retriever, but clicking one
only restores the question/top-K, not the server settings.

Runtime values are temporary and shared by all clients of this process. Restart
restores environment defaults; the UI does not write environment variables/files.
Model directory, document directory and filters still require restart. Semantic
and hybrid are disabled unless `RAG_SEMANTIC_MODEL_DIR` was configured at startup;
runtime model loading remains local-only. A configured path does not guarantee
valid weights: model/index errors leave the old runtime intact.

Start the hybrid UI with one command from the repo root:

```powershell
.\scripts\start-ui.ps1
```

The script selects the synthetic evaluation corpus, pinned local E5 model,
offline mode, and hybrid defaults (BM25 k1=1.5, b=0.75, candidate multiplier=5),
then starts the API in the foreground. After startup completes, open
http://127.0.0.1:8080/. Keep the terminal open and stop with Ctrl+C. For another
retriever or port, use `-Retriever overlap|bm25|semantic|hybrid` and `-Port 8090`;
for example `.\scripts\start-ui.ps1 -Retriever bm25 -Port 8090`. To select
another local documents directory, pass `-DocsDir "C:\path\to\docs"`. Settings
are process-local and restored in the calling PowerShell process when the server
stops. If a matching instance already listens on the selected port, the script
reuses it and opens the UI; if the port belongs to another or differently
configured instance, it reports the conflict instead of starting a second server.
Bind only to localhost:
this workspace has no authentication; both reindex and runtime configuration
mutate server state. Use a single Uvicorn worker for this local workspace:
multiple workers would have independent runtime/index state.

Browser acceptance check:

1. Index shows eight documents/eight chunks, runtime shows `hybrid`, status is Online.
2. Search `The process keeps dying at launch because a settings file disappeared`
    with Sources=3. `Pod restart investigation` should rank first. Inspect snippets,
    actions, Evidence and Response JSON; download JSON if needed.
3. Search `Контейнер постоянно перезапускается из-за отсутствующего файла настроек`.
    Expect the same first source. Change Sources to 1 and repeat.
4. Reuse an earlier query from Session queries, then clear the history. It is not
    persisted in browser storage and disappears on reload.
5. Click Reindex documents: counts stay eight/eight, previous results are cleared.
    Run the query again. Refresh index status should preserve the current results.
6. Ask an unrelated question. Semantic/hybrid may still return sources: this is
    the existing no-answer limitation, not evidence that an answer exists. Scores
    are ranking signals, not confidence. Generic actions can also be returned.
7. In Runtime select BM25, set k1=1.2, b=0.5 and candidate multiplier=8, then
    Apply settings. Active changes only after success. Run the English query:
    its Result label and JSON export must contain the applied values.
8. Apply overlap, then semantic, then hybrid and rerun the same question. BM25
    fields are disabled for overlap/semantic. A previous result retains its own
    label and score explanation until the next search; numeric scores across
    methods are not comparable. Finish with hybrid, k1=1.5, b=0.75, multiplier=5.

Apply serializes with query/reindex operations. Controls are disabled while the
index builds; semantic/hybrid reload the encoder and embeddings, so switching
can take time and temporarily needs memory for both old and replacement services.
The browser does not time out an apply/reindex operation; closing the page or a
network interruption does not cancel server work. After an unconfirmed apply,
refresh index status to read the actual active configuration before comparing.
Invalid settings return 422; build failure returns 503 and preserves old state.
Runtime bounds: 0 < k1 <= 10 (UI minimum 0.01), 0 <= b <= 1,
integer multiplier 1..50. These are local-workspace safety bounds, not quality
recommendations; BM25 parameters are inactive outside BM25/hybrid. RRF c=60 and
weights 1:1 remain fixed; corpus, model, chunker, API defaults and CLI benchmark
are unchanged. Use dev only for selecting settings, not the held-out test.

For `brain2nd`, use the existing vault command below, additionally excluding
`4. Projects/RAG/Raw Sessions`. The UI shows the actual source path and filters.
No full-document browser or arbitrary file access is exposed; snippets are plain
text. Downloaded JSON can contain private snippets: keep it outside the public repo.

## Use Obsidian Vault as Source

You can index your `brain2nd` vault directly.

```powershell
# Terminal 1: run API with external docs source
pwsh -File .\scripts\run-api.ps1 `
	-DocsDir "C:\Obsidian\brain2nd" `
	-IncludeFolders "3. Permanent Notes,4. Projects/RAG" `
	-ExcludeFolders ".git,.obsidian,attachments,draw.io"

# Terminal 2: reindex + query
Invoke-RestMethod -NoProxy -Method Post -Uri "http://127.0.0.1:8080/reindex" | ConvertTo-Json -Depth 5
pwsh -File .\scripts\query-sample.ps1 -Question "What is current RAG project status?" -TopK 5
```

Environment variables supported by app startup:
- `RAG_DOCS_DIR`
- `RAG_INCLUDE_FOLDERS` (comma-separated relative paths)
- `RAG_EXCLUDE_FOLDERS` (comma-separated relative paths)
- `RAG_RETRIEVER` (`overlap`, the unchanged default, `bm25`, or optional `semantic`/`hybrid`; restart to change)
- `RAG_BM25_K1` (default `1.5`, positive finite number) and `RAG_BM25_B`
  (default `0.75`, between `0` and `1`), used in BM25 and hybrid
- `RAG_CANDIDATE_MULTIPLIER` (default `5`, positive integer): chunk candidates per requested source before path deduplication; in hybrid, also the depth of each branch
- `RAG_SEMANTIC_MODEL_DIR` (required for `semantic`/`hybrid`): directory of a locally downloaded E5 model

## Measurable retriever (stages 1-2)

The independent [evaluation benchmark](evaluation/README.md) contains eight synthetic
runbooks and 32 annotated RU/EN questions, split into dev and held-out test families.
It compares the current token overlap with BM25 using Recall@K, Precision@K,
MRR@K, MAP@K, latency, and separate no-answer checks, both overall and by query group.
It uses no external documents, network calls, or new dependencies.

```powershell
# From the project root, evaluate defaults on dev first
.\.venv\Scripts\python.exe -m app.rag.evaluate --split dev --k 3 --output dev-results.json

# After choosing and freezing settings on dev, evaluate held-out test
.\.venv\Scripts\python.exe -m app.rag.evaluate --split test --k 3 --output test-results.json

# Opt in to BM25 without changing request/response fields
$env:RAG_RETRIEVER = "bm25"
pwsh -File .\scripts\run-api.ps1
```

BM25 builds in-memory term statistics at indexing/reindexing time and keeps short
terms such as `IO` and `IP`. The baseline tokenizer and ranking remain unchanged.
Neither method provides semantic RU-to-EN retrieval or calibrated abstention:
a nonempty result list (or a high ranking score) does not establish that the answer exists.
Local semantic and hybrid RRF retrieval are available as opt-ins; actual generation
remains a later stage.

## Optional local semantic retrieval

This CPU-only iteration uses `intfloat/multilingual-e5-small`, exact cosine search
over an in-memory embedding matrix, and the same chunks/API/path deduplication.
Lexical modes do not import ML packages or load a model. Base dependencies and
the default Docker/Helm/manifests remain lexical-only; the following is a local
development setup, not a deployment change.

```powershell
# Optional dependencies, separate from the lightweight base requirements
.\.venv\Scripts\python.exe -m pip install -r requirements-semantic.txt

# Explicit one-time public weight download, pinned to a model revision.
# Store outside the repository; no documents are sent to Hugging Face.
$revision = "614241f622f53c4eeff9890bdc4f31cfecc418b3"
$modelDir = Join-Path $env:LOCALAPPDATA "infrastructure-rag\models\multilingual-e5-small-614241f"
$files = @(
    "config.json", "modules.json", "sentence_bert_config.json",
    "1_Pooling/config.json", "special_tokens_map.json", "tokenizer.json",
    "tokenizer_config.json", "sentencepiece.bpe.model", "model.safetensors"
)
foreach ($file in $files) {
    $destination = Join-Path $modelDir ($file.Replace("/", "\"))
    New-Item -ItemType Directory -Force -Path (Split-Path $destination) | Out-Null
    Invoke-WebRequest `
        -Uri "https://huggingface.co/intfloat/multilingual-e5-small/resolve/$revision/$file" `
        -OutFile $destination -TimeoutSec 300
}

$env:RAG_RETRIEVER = "semantic"
$env:RAG_SEMANTIC_MODEL_DIR = $modelDir
pwsh -File .\scripts\run-api.ps1
```

Runtime model loading uses `local_files_only=True`, `trust_remote_code=False`,
CPU and four PyTorch threads. `query: ` prefixes questions; `passage: ` prefixes
the chunk's title and body (not path/tags). Documents are embedded at startup and
reindex; questions are embedded per request. Reindex reuses the loaded model and
retains the old index if embedding the new corpus fails. Vectors are not persisted.

Inputs exceeding the model's token limit (including prefix/title/special tokens)
are rejected, not silently truncated. Oversized questions return HTTP 422;
oversized corpus chunks fail startup/reindex explicitly. Chunking itself is
unchanged. Missing directories, dependencies or model assets fail explicitly,
without switching to lexical results.

**No calibrated abstention is implemented.** With a nonempty corpus semantic
search returns nearest candidates even for questions without an answer, including
nonpositive cosine scores. A high cosine score is not confidence. Use the
[four-retriever evaluation](evaluation/README.md#optional-semantic-comparison)
to inspect both improvements and false positives.

## Optional hybrid RRF retrieval

Hybrid uses the same local model/dependencies as semantic, plus BM25. It fuses
**chunk ranks**, not raw BM25/cosine scores, with equal weights:
`score(chunk) = 1/(60 + rank_bm25) + 1/(60 + rank_semantic)`.
Ranks start at one; a missing branch contributes zero. The smoothing constant
60 and equal weights are fixed initial settings, not tuned or exposed as new
environment variables.

Each branch retrieves up to `top_k * RAG_CANDIDATE_MULTIPLIER` chunks from the
same indexed chunk list. Fusion joins by chunk position, preserving different
chunks of the same document; it never joins by path, snippet or raw score.
Ties use corpus/chunk order. The fused list is capped to that candidate depth,
then the existing document-path dedup returns at most `top_k` sources.
Source `score` is now an RRF score, not cosine similarity or confidence.

Stop the existing API with `Ctrl+C` before restarting. In terminal 1, use the
synthetic evaluation corpus for the following reproducible questions:

```powershell
Set-Location C:\Obsidian\infrastructure-rag
$env:RAG_RETRIEVER = "hybrid"
$env:RAG_SEMANTIC_MODEL_DIR = Join-Path $env:LOCALAPPDATA "infrastructure-rag\models\multilingual-e5-small-614241f"
$env:RAG_INCLUDE_FOLDERS = ""
$env:RAG_EXCLUDE_FOLDERS = ""
$env:RAG_BM25_K1 = "1.5"
$env:RAG_BM25_B = "0.75"
$env:RAG_CANDIDATE_MULTIPLIER = "5"
$env:HF_HUB_OFFLINE = "1"
$env:TRANSFORMERS_OFFLINE = "1"
pwsh -File .\scripts\run-api.ps1 -DocsDir "$PWD\evaluation\corpus"
```

In terminal 2 (PowerShell 7):

```powershell
Invoke-RestMethod -NoProxy http://127.0.0.1:8080/healthz
Invoke-RestMethod -NoProxy http://127.0.0.1:8080/info | ConvertTo-Json -Depth 5

$body = @{
    question = "The process keeps dying at launch because a settings file disappeared"
    top_k = 3
} | ConvertTo-Json
$r = Invoke-RestMethod -NoProxy -Method Post `
    -Uri http://127.0.0.1:8080/query -ContentType "application/json; charset=utf-8" `
    -Body ([System.Text.Encoding]::UTF8.GetBytes($body))
$r | ConvertTo-Json -Depth 6
if ($r.sources[0].path -ne "pod-restarts.md") { throw "Unexpected top source" }
```

`/info` must show `evaluation\corpus`, eight documents and eight chunks; it does
not expose the active retriever/model. On the first dev measurement hybrid ranks
`pod-restarts.md` first for this paraphrase (semantic alone ranks it second).
Repeat with the Russian question
`Контейнер постоянно перезапускается из-за отсутствующего файла настроек`;
expect the same top document. All HTTP request/response fields remain unchanged.

For four-method metrics and automated tests, see the
[hybrid benchmark and validation commands](evaluation/README.md#hybrid-rrf-dev-measurement-2026-11-10).
Hybrid reuses the loaded encoder on reindex, rebuilds both indexes before replacing
the current state, and propagates semantic errors, including query HTTP 422.
It adds no vector DB, ANN, new chunker or generator. **No-answer remains unsolved**:
with a nonempty corpus the semantic branch still contributes candidates, even when
BM25 returns nothing. RRF cannot turn nearest vectors into evidence that an answer exists.

- `GET /healthz`
- `GET /info`
- `POST /query` — structured RAG response (`summary`, `evidence`, `recommended_actions`, `sources`)
- `POST /reindex` — reload markdown documents without restarting the app
